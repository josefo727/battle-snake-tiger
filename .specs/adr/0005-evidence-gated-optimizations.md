# ADR 0005 - Evidence-gated optimizations and a parallel-ready search

- **Status:** accepted
- **Date:** 2026-09-09
- **Deciders:** José R. Gutierrez
- **Context links:** `../001-duel-search/spec.md` non-goals; Constitution Articles VI, XI, XIV

## Context

Transposition tables, incremental hashing, and multi-threaded search can each
multiply effective depth, but each adds state, nondeterminism risk, and code.
The approved spec forbids adopting them without measured justification. The
project owner also wants the strongest defensible engine.

## Options considered

### Option A - Adopt every known speedup up front

- Pros: highest possible depth early.
- Cons: unmeasured complexity; hard to attribute strength changes; risks
  nondeterministic bugs before a baseline exists.
- Effort / risk: high, unattributable.

### Option B - Baseline first, then adopt each optimization when a measurement justifies it

- Pros: every addition has a recorded reason and a recorded effect; the
  baseline gives a control for sparring comparisons.
- Cons: the first sparring numbers are for a simpler engine.
- Effort / risk: low process overhead.

## Decision

Option B. A profiling task records nodes/second, iteration depth, and the fraction
of visited positions that repeat within a search. A transposition table with
Zobrist keys (64-bit, generated by a const splitmix64 sequence, depth-preferred
replacement, stored moves re-validated) is adopted in this feature only if the
measured repeat rate exceeds the threshold set in `plan.md`. Search is written
as pure functions over `Copy` positions with an allowance object, so a
multi-threaded root split can be added in a later feature (planned as 002) with
no rewrite; parallelism itself is out of this feature's scope.

## Consequences

- **Positive:** attributable strength gains; a deterministic single-thread
  baseline for regression comparison.
- **Negative:** the first sparring report reflects a baseline engine.
- **Follow-ups:** profiling task precedes the transposition-table task.

## Constitution impact

None.
